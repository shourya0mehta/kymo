Polish you can prove.

kymo opens your web app in a real browser and uses it the way a person would. It times every press, watches every frame, and points each slow or jumpy moment at the line of code behind it. Claude makes the fix. kymo measures again and keeps it only if it helped.

The loop has its own test in the repo. A quick fix for a teleporting panel, transition: left, removes the jump but animates a layout property, so it is reverted. The transform version is kept.

Every finding points at a line.

The report shows what happened over time, where to look, and how to check the fix. This finding is real, from the jank zoo.

WarningFEEL-01slow-ack, on /

Slow feedback after a click

Clicking button "Like 0" took 619 ms to show any change, with no pressed state while held.

  • zoo.js:6:45its click handler
  • zoo.css:89.btn:hover
  • zoo.css:77.btn

Acknowledge the click in the next frame: a pressed style on :active, an optimistic update, or a pending state that appears immediately. Keep the slow work, but stop making the user wait to see that the click landed.

Replay it

Only the interactions you touched, so checking a fix takes seconds.

kymo audit --trace .kymo/trace.json --only slow-ack

Keep or revert

Exit 0 keeps the change. Exit 3 means put it back.

kymo verify --before before.json --after after.json --target FEEL-01-5c130

We ran kymo on this page before shipping it

Desktop and phone, 35 interactions, about two minutes. kymo verify kept every fix: 3 resolved, nothing new, nothing slower.

  • Dead click (FEEL-03). The Archive button in the focus demo did nothing when pressed. It now answers with "Archived".
  • Teleport (MOT-09). The Copy button jumped 25 px sideways when its label grew to "Selected". It now has a fixed width.
  • Small touch targets (CRAFT-09). On a phone, six controls were under 44 px, the smallest 48 by 24. The Copy buttons and footer links now reach 44.
  • kymo's own mistake (FEEL-01, FEEL-03). It clicked the skip link, which sits above the page until it has focus, so no mouse can reach it. kymo now leaves off-page controls to its keyboard pass.

Two minutes to the first report.

kymo runs on Node 20 or newer with Playwright's Chromium. It is not on npm yet, so it installs from GitHub.

Run it on your app

Start your dev server, then point kymo at it.

terminal
# once
git clone https://github.com/shourya0mehta/kymo
cd kymo && npm install
npx playwright install chromium

# every time
node dist/cli.js audit http://localhost:5173 \
  --viewports desktop,mobile
open .kymo/report.html

Hand it to Claude

The skill walks Claude through the loop: baseline, one fix at a time, verify, commit or revert.

terminal
cp -r skills/kymo ~/.claude/skills/

# then, in Claude Code
Polish my app with kymo.

Gate pull requests

Fails only on findings your saved baseline doesn't already have, and annotates the lines in the diff.

.github/workflows/feel.yml
- uses: shourya0mehta/kymo@main
  with:
    url: http://localhost:4173
    viewports: desktop,mobile
