Polish you can prove.

kymo opens your web app in a real browser and uses it the way a person would. It times every press, watches every frame, and points each slow or jumpy moment at the line of code behind it. Claude makes the fix. kymo measures again and keeps it only if it helped.

Measure, fix, verify, keep.

Claude does the part a measurement can't: writing the change. Everything else is measured, before and after.

  1. 1

    Measure

    kymo finds every control, field and route, then presses, types, tabs, hovers and scrolls through them in Chromium, on desktop and a phone.

    kymo
  2. 2

    Point

    Each finding names the CSS rule, event handler or script behind it, with a timeline of what happened.

    kymo
  3. 3

    Fix

    Claude makes the smallest change the rule asks for, on a branch, one finding at a time.

    Claude
  4. 4

    Verify

    kymo replays exactly the same interactions. Anything new, or anything slower, counts against the fix.

    kymo
  5. 5

    Keep or revert

    A fix that resolves its finding and breaks nothing is committed. Anything else is rolled back.

    kymo and git

The loop has its own test in the repo. A quick fix for a teleporting panel, transition: left, removes the jump but animates a layout property, so it is reverted. The transform version is kept.

Two minutes to the first report.

kymo runs on Node 20 or newer with Playwright's Chromium. It is not on npm yet, so it installs from GitHub.

Run it on your app

Start your dev server, then point kymo at it.

terminal
# once
git clone https://github.com/shourya0mehta/kymo
cd kymo && npm install
npx playwright install chromium

# every time
node dist/cli.js audit http://localhost:5173 \
  --viewports desktop,mobile
open .kymo/report.html

Hand it to Claude

The skill walks Claude through the loop: baseline, one fix at a time, verify, commit or revert.

terminal
cp -r skills/kymo ~/.claude/skills/

# then, in Claude Code
Polish my app with kymo.

Gate pull requests

Fails only on findings your saved baseline doesn't already have, and annotates the lines in the diff.

.github/workflows/feel.yml
- uses: shourya0mehta/kymo@main
  with:
    url: http://localhost:4173
    viewports: desktop,mobile
